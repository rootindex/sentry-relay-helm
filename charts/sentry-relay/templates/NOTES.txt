MANAGED MODE: relay only accepts events after its public key is registered
with your Sentry. One-time step, in the Sentry UI:
  Organization Settings -> Relays -> New Relay Key -> paste the public key
  (relay credentials show, or .public_key in credentials.json)
If registration is missing or fails, relay accepts NO events. The readiness
probe stays failing until relay authenticates with the upstream: register the
key BEFORE installing, or `helm install --wait` / `--atomic` will time out.
If pods are Running but Unready, check `kubectl logs` for auth errors.

After rotating the credentials Secret in place, run
`kubectl rollout restart deployment/{{ include "sentry-relay.fullname" . }}`
(relay reads credentials only at startup) and register the new public key.
